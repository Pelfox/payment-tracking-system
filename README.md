# Система отслеживания платежей

Этот проект представляет собой простое веб-приложение, позволяющее отслеживать
платежи. Он может быть полезен для отслеживания, например, кредитных или
регулярных платежей, а также для упрощения учета расходов. 

## Предметная область

Предметная область проекта - отслеживание платежей. Эта система предназначена
для регистрации и мониторинга информации об оплате счетов пользователями. В
рамках предметной области рассматриваются основные данные о платеже:
плательщик, номер счета, сумма к оплате, сумма произведенного платежа, способ
оплаты и дата платежа. На основе введенных данных система может определить
статус платежа: счет оплачен полностью, частично или с переплатой. 

## Основные сущности

Основная сущность системы - **платеж**. Она содержит информацию о сумме
платежа, дате платежа, способе оплаты и результате обработки платежа. В
предметной области также можно выделить следующие сущности:

* **Плательщик**: пользователь или клиент, совершающий платеж;
* **Счет**: объект, на который производится платеж;
* **Платеж**: операция по внесению денежных средств;
* **Статус платежа**: результат сравнения суммы платежа с суммой счета.

### Основные функции

* ввод данных о плательщике;
* ввод номера счета;
* ввод суммы, необходимой для оплаты;
* ввод фактически оплаченной суммы;
* выбор способа оплаты;
* расчет комиссии в зависимости от способа оплаты;
* сравнение суммы платежа с суммой на счете;
* определение статуса платежа: полная оплата, частичная оплата или переплата;
* расчет оставшейся суммы или суммы переплаты. 

### Веб-интерфейс и статические файлы

Общая шапка содержит логотип и ссылки на главную страницу, платежи и сводку.
CSS, JavaScript и SVG-логотип находятся в `homepage/static/homepage/` и
подключаются в шаблонах через `{% static %}`. Собственные стили оформляют шапку,
навигацию, таблицу и статусы платежей. JavaScript позволяет фильтровать список
платежей по статусу и показывает количество подходящих записей. Без JavaScript
все платежи остаются доступными в таблице.

Проверка и запуск приложения:

```bash
python manage.py check
python manage.py runserver
```

### План развития проекта

После выхода первой версии планируется поддержка другой системы управления
базами данных (СУБД). Помимо этого, планируется добавление системы
экспортирования данных пользователя в удобном для него формате.

### Импорт JSON в SQLite (ПР7)

Из корня проекта в активированном виртуальном окружении выполните:

```bash
python -m db.import_json
```

Скрипт `db/import_json.py` переносит результаты платежей из
`data/payments.json` в `data/payments.sqlite`. Формат JSON совпадает с форматом
существующего `JsonPaymentRepository`: список объектов `PaymentResult` с
вложенным `payment`, его UUID, плательщиком, счётом и датой операции.
Таблицы при необходимости создаются из `sql/schema.sql`.

Для других путей используйте параметры:

```bash
python -m db.import_json --source data/payments.json --database data/payments.sqlite
```

Сначала проверяется весь файл, затем в одной транзакции импортируются
плательщики, счета и платежи. Деньги сохраняются целыми копейками,
даты приводятся к UTC (дата без часового пояса считается UTC).
Плательщики объединяются по полному имени, снимки счетов — по плательщику,
номеру и сумме. Повторный запуск обновляет платежи по UUID без дубликатов;
операции, которых нет в новом файле, не удаляются. Исходный JSON не изменяется.
При ошибке записи транзакция откатывается; скрипт завершится с кодом 1 и
сообщением об ошибке. После добавления платежей через старый JSON-интерфейс
запустите импорт повторно, чтобы увидеть новые данные на сайте.
